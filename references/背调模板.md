# 公司背调文档模板（八段制）

复制以下全文到 `工作N+岗位名（公司简称）\公司背调_公司简称.md`，逐段替换内容。
高风险岗位文件名加 `_高风险` 后缀；需要写成长路径分析时加 `_含成长路径`。

```markdown
# 公司背调 · 公司全称（岗位名）

> 岗位：XXX ｜ 薪资（含几薪）｜ 地点 ｜ 经验/学历要求 ｜ 招 N 人（更新时间）
> HR：姓名（头衔，活跃时间）｜ 渠道：BOSS直聘/猎聘
> 背调日期：YYYY-MM-DD

## 一、基本盘

| 项目 | 内容 |
|---|---|
| 全称 | |
| 隶属/股权 | |
| 成立与沿革 | |
| 主营 | |
| 规模 | ⚠️ 平台标注 XX 人 vs 工商参保 XX 人（拆水分） |
| 资质/亮点 | |
| 风险线索 | |

**一句话**：（这家公司到底是什么，30 字内说清）

## 二、岗位性质（是不是外包/驻场）

明确给出判断：甲方直招 / 集团子公司 / 乙方供应商（项目制）/ 人力外包 / 驻场 / 中介代发，并写出判断依据（发布主体是谁、HR 头衔是什么、是否写"驻场""派遣"）。
⚠️ 用户最关心这一条，不许含糊。

## 三、岗位内容（JD 原文拆解）

把 JD 职责逐条列出，关键要求加粗。不要改写，原文照录便于面试对答。

## 四、员工风评

- 本公司：能查到的点评（职Q/脉脉/看准）要点；查不到就写"未检索到独立点评"
- 所属体系：（子公司看母公司体系的公开口碑）
- 负面线索：劳动争议、欠薪、裁员、被执行等（有就写，没有写"未检索到"）

## 五、适配度评估

**匹配度约 XX%**，一句话定性（这份 JD 与履历的同源程度）。

| JD 要求 | 我的对应 |
|---|---|
| （逐条抄 JD 硬要求） | （引 profile.md 里的真实经历与数字） |

唯一缺口：（缺什么，用什么经历去接）
**话术落点**："（可直接引 JD 原文的一句话）"

## 六、风险信号

| 信号 | 程度 | 说明 |
|---|---|---|
| | 🟢 低 / 🟡 中 / 🔴 高 | |

## 七、投递建议

**投 / 不投 / 练手投** + 优先级（第一/第二/练手）+ 年包换算（月薪 × 薪数）+ 面试前要补的功课。

## 八、面试必问

1. 岗位量级与接手时的阶段？（覆盖范围、日活、数据量）
2. 汇报线与团队规模？
3. 指标/口径谁定？我能影响哪些环节？
4. 薪资构成（几薪是否足额、绩效占比、试用期折扣）？
5. 出差/驻场频率？（实施类必问）
6. 该岗位是新增还是补缺？上一位为什么走？
```

## 写作要求

- **每条结论都要有依据**：写"疑似外包"必须跟着"因为 HR 是 XX 公司的人 / 薪资由 XX 发放 / JD 写了驻场"。
- 平台标注的人数一律去工商口径核对，两边不一致就写进"规模"行。
- 查不到信息 ≠ 略过，本身就是结论（尤其对新公司）。
- 用户追问"这种高薪岗怎么才能拿到"时，追加成长路径章节：**现实阶梯**（阶段/岗位/年包区间/怎么走）+ 6-12 个月动作（按性价比排序）+ 一句实话（不建议横跳到硬门槛差太远的赛道）。
