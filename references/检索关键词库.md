# 背调检索关键词库

一家公司按下面六个方向搜，2-5 次搜索即可。**查不到就写"查不到"——这本身是结论。**

```
"公司全称" 怎么样 外包 口碑              ← 第一搜，快速定性
"公司简称" 员工 点评 职Q 脉脉 看准        ← 员工风评
"公司全称" 参保人数 注册资本              ← 拆平台标注的规模水分
"公司全称" 母公司 子公司 股东 收购 控股    ← 股权关系，判断是甲方还是外包/子公司
"公司全称" 裁员 欠薪 被执行 劳动仲裁       ← 风险线索
"公司全称" 融资 轮次 上市 新闻            ← 业务现状与面试谈资
"公司名" "岗位名" 面试 面经               ← 可选，面试侧重
```

## 判断要点

**是否外包**（用户最关心）
- 发布主体 = 用工主体？HR 是不是本公司员工？
- JD 是否出现"驻场""派遣""外包项目""客户现场"？
- 公司主营是不是"人力服务/软件外包/信息技术服务"？
- 若为集团子公司：属于甲方系还是乙方系（对履历是升级还是平移）？

**规模水分**
- 招聘平台标的人数是"集团口径"，与工商年报参保人数常差 10 倍以上，两个数都写进背调。

**风评**
- 大公司看母公司体系口碑 + 子公司自身有无独立条目；小公司查不到就注明"未检索到独立点评"。

**更新日期与活跃度**
- 岗位更新时间太旧（1-3 个月以上）→ 汇报时提醒"先确认是否还在招"。
- HR 的"刚刚活跃/几小时前活跃"会影响首触的时效策略。

## 注意

新注册 + 小注册资本 + 标注人数巨大 + 全网零信息 + 中介代发 + 高薪远程 = 虚假招聘高发组合，按 `判定规则.md` 的红旗处理。
